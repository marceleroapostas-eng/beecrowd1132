# Beecrowd 1132 - Múltiplos de 13

## Descrição
Programa desenvolvido em Java para calcular a soma dos números inteiros que não são múltiplos de 13, dentro de um intervalo informado.

## Linguagem
Java

## Entrada
O programa recebe dois números inteiros X e Y, que definem os limites do intervalo.

## Saída
Imprime a soma de todos os números inteiros que não são divisíveis por 13 entre X e Y, incluindo os extremos.
